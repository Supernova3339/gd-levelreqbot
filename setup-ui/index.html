Twitch API Setup

Configure Twitch API integration for enhanced features:

Creating a Twitch Application

  1. Go to Twitch Developer Console
  2. Create a new application with name "GD-LevelReqBot"
  3. Set OAuth Redirect URL to: http://localhost:24363/auth/twitch/callback
  4. Set Category to "Chat Bot"
  5. After creating, copy the Client ID and Client Secret below

Default Commands

The following commands will be available:

  • !r [levelID] - Add a level to the queue
  • !position [levelID] - Check position in queue
  • !info [levelID] - Get level information
  • !remove [levelID] - Remove your level from queue
  • !next - Go to next level (mods only)
  • !clear - Clear the queue (mods only)
